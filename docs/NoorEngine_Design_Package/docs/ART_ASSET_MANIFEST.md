## Branding recommendations (not decisions)

- Use one primary wordmark and derive simple, monochrome, small-size variants.
- Prefer a legible icon at 24/32/64 px; elaborate details that vanish at small sizes should be removed for app icons.
- Create a native vector master after selecting the brand direction, rather than trying to pretend these PNGs are SVG files.
- Preserve the Bad Ideas Works credit but avoid making the small app icon illegible.
- Keep dark/light usage and readability in mind; the dark-filled wordmarks may need adapted variants on dark editor surfaces.

## Transparency note

The logo/emblem PNGs include alpha transparency. The full-workspace UI mockup is a standard full-frame screenshot concept; the cleaner UI mockup has an RGBA channel but is likewise intended as a full-frame interface reference, not a transparent logo.
